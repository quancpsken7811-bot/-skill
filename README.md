# 朋友圈海报 Skill

把真实聊天截图快速制作成朋友圈反馈海报。插件内置场景底图与固定版式，使用时只需提供主题标题和一张真实聊天截图。

## 安装

在 Codex 终端粘贴并运行这一行：

```bash
codex plugin marketplace add quancpsken7811-bot/-skill --ref main && codex plugin add education-poster-hub@moments_poster_team
```

安装后，新开一个 Codex 任务，直接输入：

> 用朋友圈海报 Skill，主题是“陪跑用户反馈”，用这张聊天截图生成朋友圈海报。

## 使用规则

- 只传主题标题和真实聊天截图即可；插件会使用内置底图与版式。
- 聊天中的头像、时间、金额和文字属于真实反馈证据，不会被改写或虚构。
- 如果要更换底图、品牌 Logo 或页脚，可在任务里额外说明。
