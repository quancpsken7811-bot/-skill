# 朋友圈反馈海报

把真实客户反馈以一张高质感朋友圈海报呈现。核心不是重做聊天记录，而是以固定的“场景底图 + 标题区 + 指标区 + 居中聊天卡片 + 页脚”版式，让不同主题和截图能稳定替换。

## 何时使用

当用户要制作、修改或批量制作“朋友圈客户反馈海报”“陪跑用户反馈”“学员成交/GMV/成果反馈海报”时使用。

不要用于凭空编造学员聊天、业绩、头像、金额或任何客户证据；缺少真实截图时，向用户索取截图或改为非证据型案例海报。

## 团队最简输入

使用插件内置默认模板时，团队成员只需要提供两项：

1. **主题标题**：例如“陪跑用户反馈”“学员成果反馈”“训练营反馈”。它替换海报顶部主题。
2. **真实聊天截图**：完整、清晰可读；它替换中央聊天卡片内容。

默认场景底图、版式、Logo 位置、页脚和配色均从插件资源中读取：

- `assets/default-scene-background.jpg`：固定场景底图。
- `assets/default-layout-reference.png`：固定版式、留白与字体层级参考。

用户明确要求时，才额外替换底图、Logo、页脚或卡片主色。

## 固定版式与可改字段

保留下列层级，避免每次重新发明版式：

- 顶部左侧：品牌 Logo 加主题标题。
- 中间左侧：带细描边与轻阴影的圆角聊天卡片。
- 右侧：纵向排布的核心成果/指标。
- 底部：一句品牌或业务说明。

默认只替换：主题标题、聊天截图。

按需允许替换：核心指标、底图、Logo、页脚、卡片主色。

不要随意改变：信息层级、聊天卡片占画面约 55% 宽度的视觉重心、右侧指标区和底部说明区的留白关系。详细尺寸与质量检查见 [版式规范](references/layout.md)。

## 制作流程

1. 读取 `assets/default-scene-background.jpg` 作为外层场景底图，读取 `assets/default-layout-reference.png` 作为固定版式参考；用户未提供新底图时不得要求补传底图。
2. 用用户输入的主题标题替换顶部主题文案；场景底图只做适度明暗和裁切处理，不能抢聊天内容。
3. 把聊天截图完整放入中央卡片。消息、头像、时间、金额、气泡颜色、文字都要保留，严禁改写或重新生成聊天证据。
4. 右侧核心指标只能使用用户明确提供的数值，或聊天截图中清晰、可逐字核验的原始数值；无法确认时省略指标，不得沿用模板中的“GMV破9万”或猜测金额。
5. 根据主题和底图统一卡片描边、阴影、标题及指标色。优先低饱和商业色，保证截图仍是视觉主角。
6. 输出竖版 PNG，并在交付前按质量清单检查。

## 图片工具与校验

这是一项位图合成任务。先加载 `imagegen` 技能，并优先使用其内置图片编辑/合成功能。若用户要求文字或截图绝对不可变，必须强调“原图植入、禁止重绘和改字”，并人工检查每一处聊天文案、金额和时间。

交付前逐项检查：主题是否正确、原截图是否被改字或截断、右侧指标是否来自可核验信息、卡片边缘是否干净、底图与文字是否有足够对比、没有水印或虚构信息。

## 交付

保存为新文件，建议命名：`朋友圈反馈海报-<主题>-<日期或版本>.png`。在回复中展示预览并给出可下载的绝对路径。
