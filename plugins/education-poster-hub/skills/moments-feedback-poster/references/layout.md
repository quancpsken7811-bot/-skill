# 朋友圈反馈海报版式规范

## 默认画布

- 竖版 1122 × 1402 px；允许同比例放大导出。
- 场景底图全画布覆盖，以真实室内、办公、自然光环境为优先。
- 聊天卡片位于左中部，约占画面宽度的 54%–58%、高度的 74%–78%。

## 信息结构

1. 顶部：Logo 与主题标题。主题控制在 4–8 个汉字为宜。
2. 中部：聊天卡片为第一视觉重点。可加 1–2 px 暖金描边与极轻的阴影。
3. 右侧：纵向排一组关键成果，保持大字号、短文案、清晰断行，例如“GMV\n破\n9\n万”。
4. 页底：不超过一行的品牌说明，使用小号高对比文字和两侧短线。

## 色彩

- 底图偏冷绿或中性时，聊天卡片可使用焦糖、棕橙或暖奶油色，形成自然对比。
- 截图本身已经有强烈红棕背景时，优先保留原色；外框使用低饱和金色，不额外叠加强特效。
- 若用户指定替换聊天背景，可采用奶油、杏橙、焦糖等商业暖色，但文字图层应退至背景层，不能干扰气泡阅读。

## 证据保护

- 禁止补写、删改或润色聊天文字与金额。
- 禁止替换头像、时间或消息气泡。
- 裁切时保留完整对话主线；若必须裁切，先向用户确认。
